---
title: "Запрос к провайдеру модели"
description: "Один обмен: обвязка отправляет контекст, провайдер возвращает ответ. Один ход может включать много запросов."
---

Один обмен между [обвязкой](./Harness.md) и [провайдером модели](./Model%20provider.md). Обвязка отправляет текущий [контекст](./Context.md), провайдер возвращает один ответ — [вызов инструмента](./Tool%20call.md) или итоговый текст. Сообщение пользователя может породить много запросов, если [агент](./Agent.md) использует [инструменты](./Tool.md): каждый [результат инструмента](./Tool%20result.md) вызывает следующий запрос.

Каждый запрос несёт всё: [системный промпт](./System%20prompt.md), весь разговор, все результаты инструментов. [Модель](./Model.md) [не хранит состояние](./Stateless.md), поэтому между запросами провайдер ничего не помнит. Сороковой запрос повторяет тридцать девятый и добавляет ещё один результат. [Кэш префикса](./Prefix%20cache.md) делает это повторение дешевле.

Запрос — также единица расчёта стоимости. [Входные](./Input%20tokens.md), [выходные токены](./Output%20tokens.md) и скидки кэша считаются для каждого запроса. Поэтому короткий вопрос может стоить неожиданно дорого. Цена зависит не от длины сообщения, а от числа запросов и размера контекста в каждом.

Запрос следует отличать от [хода](./Turn.md). Ход — один обмен с вами. Просьба «исправь падающий тест» может дать такую цепочку:

| Запрос | Ответ модели                       | Действие обвязки                      |
| ------ | ---------------------------------- | ------------------------------------- |
| 1      | Вызов инструмента: запустить тесты | Запускает, добавляет вывод с ошибкой  |
| 2      | Прочитать файл теста               | Добавляет содержимое                  |
| 3      | Прочитать исходный файл            | Добавляет содержимое                  |
| 4      | Изменить исходный файл             | Применяет правку, добавляет результат |
| 5      | Снова запустить тесты              | Добавляет успешный вывод              |
| 6      | Итог: «исправлено, тесты проходят» | Показывает ответ вам                  |

Шесть запросов за один ход, каждый с полным контекстом. Чтобы понять расход [токенов](./Token.md), считайте запросы, а не ходы.

_Пример:_

«Один вопрос потратил сорок тысяч токенов?»

«Посмотри на инструменты: двенадцать grep, восемь чтений, четыре правки. Каждый результат создаёт новый запрос, и вся накопленная [сессия](./Session.md) отправляется заново».
