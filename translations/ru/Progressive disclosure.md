---
title: "Загрузка по необходимости"
description: "В контекст загружается только нужное сейчас; остальное остаётся доступным по кратким указателям."
---

Загрузка только того [контекста](./Context.md), который нужен [агенту](./Agent.md) сейчас, с [указателями](./Context%20pointer.md) на остальное. Понятие пришло из дизайна интерфейсов: пользователю показывают нужные для текущей задачи элементы, остальные раскрываются по действию.

Контекст имеет двойную цену. Каждый заранее загруженный [токен](./Token.md) оплачивается как [входной](./Input%20tokens.md) на каждом [ходе](./Turn.md) и расходует [бюджет внимания](./Attention%20budget.md), нужен он или нет. Если заполнить [AGENTS.md](./AGENTS.md.md) полным руководством по стилю, развёртыванию и базе данных, агент станет хуже учитывать всё это. Нужные инструкции размываются ненужными. Симптом: агент игнорирует правило, которое точно есть в контексте, но скрыто среди остального.

Подход меняет порядок загрузки. Постоянный слой остаётся небольшим: предложение о теме и путь к подробностям. Агент читает стиль при создании компонента, инструкцию развёртывания — при выпуске, а при исправлении теста не читает ни то ни другое. [Навыки](./Skill.md) воплощают этот подход в [обвязке](./Harness.md): краткое описание загружается в каждой [сессии](./Session.md), полная инструкция — при подходящей задаче.

_Пример:_

«Вставить всё руководство по стилю в AGENTS.md?»

«Лучше оформи навык, который загружается при работе над компонентом. Всё из AGENTS.md оплачивается на каждом ходу».
