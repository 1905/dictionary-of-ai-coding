---
title: "Инструмент"
description: "Функция, доступная агенту через обвязку: Read, Write, Bash, Search. Позволяет видеть и изменять окружение."
---

Функция, которую [обвязка](./Harness.md) предоставляет [агенту](./Agent.md): Read, Write, Bash, Search. Через инструменты агент воспринимает [окружение](./Environment.md) и действует в нём. Он видит его только через [результаты](./Tool%20result.md), а меняет только через [вызовы](./Tool%20call.md). Каждый вызов требует дополнительного [запроса к провайдеру](./Model%20provider%20request.md): модель должна получить результат, прежде чем решить, что делать дальше.

Обычный набор инструментов:

| Инструмент | Что делает                                                    |
| ---------- | ------------------------------------------------------------- |
| Read       | Возвращает содержимое файла                                   |
| Write      | Создаёт или меняет файл в [файловой системе](./Filesystem.md) |
| Bash       | Запускает команду оболочки и возвращает вывод                 |
| Search     | Ищет файлы или текст по шаблону в коде                        |

Определение инструмента состоит из имени, описания и схемы параметров. Обвязка передаёт эти определения [модели](./Model.md) с запросом. Модель выбирает инструмент так же, как создаёт любой текст: записывает [токены](./Token.md), в данном случае структурированный вызов с аргументами. Сама она ничего не исполняет. Обвязка читает вызов, запускает функцию и возвращает результат.

Набор инструментов задаёт возможности агента. Даже сильная модель с узким набором остаётся ограниченным агентом и пытается решить всё доступными средствами. Поэтому агенты так часто используют Bash: одна оболочка открывает доступ к большей части системы. Для отдельной возможности лучше добавить специальный инструмент. [MCP](./MCP.md) стандартизирует подключение внешних инструментов.

Определения занимают [контекст](./Context.md) даже до первого вызова. Большой набор имеет постоянную стоимость, а похожие описания затрудняют правильный выбор.

_Пример:_

«Может агент напрямую запросить staging?»

«Добавь `psql` с доступом только для чтения. Без подходящего инструмента всё за пределами файловой системы ему недоступно».
