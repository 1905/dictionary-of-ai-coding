title: "Песочница"
description: "Изолированное окружение — контейнер, виртуальная машина или ограниченная оболочка. Ограничивает последствия действий агента."
---

Изолированное [окружение](./Environment.md), в котором работает [агент](./Agent.md): контейнер, виртуальная машина, временная [файловая система](./Filesystem.md) или оболочка с ограничениями. Даже если агент выполнит разрушительную команду или загрузит вредоносные данные, ущерб ограничен. Это основа безопасности для работы [AFK](./AFK.md).

Песочница и [режим разрешений](./Permission%20mode.md) решают задачу с разных сторон. Разрешения спрашивают перед действием; песочница ограничивает, куда действие сможет дотянуться. Запросы требуют [вашего участия](./Human-in-the-loop.md), каждый прерывает работу. Постоянно спрашивающая сессия почти не автономна. Песочница расходует инфраструктуру вместо внимания: чем сильнее изоляция, тем меньше вопросов нужно задавать.

Уровни изоляции:

| Уровень               | Что это                                                                         | Что ограничивает                         |
| --------------------- | ------------------------------------------------------------------------------- | ---------------------------------------- |
| Ограниченная оболочка | Ограничения ОС вокруг каждой команды                                            | Запись вне проекта, доступ к сети        |
| Контейнер             | Свежая файловая система без подключённых учётных данных, удаляемая после работы | Действия агента внутри его машины        |
| VM / cloud            | Полностью отдельная машина, часто предоставляемая обвязкой                      | Всё, включая выход через уязвимости ядра |

Песочница не сдерживает действия, которым разрешено покидать её. Агент с вашими данными git может отправить коммиты; с доступом к сети — вызвать производственный API. Сначала решите, что может пересекать границу, затем выбирайте степень изоляции.

_Пример:_

«Хочу оставить [bypass-permissions](./Agent%20mode.md) на ночь, но пока не уверен».

«Запусти в песочнице: новый контейнер, без учётных данных и выхода в сеть. В худшем случае пострадает его собственная файловая система, и контейнер можно удалить».
