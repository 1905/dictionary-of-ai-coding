---
title: "Прототипирование"
description: "Быстрая рабочая версия помогает принять решения, которые невозможно надёжно обсудить только словами."
---

[Агент](./Agent.md) создаёт быструю черновую версию, когда разговора недостаточно и нужен реальный предмет обсуждения.

[Интервью](./Grilling.md) проясняет решения словами. Разговор дешёв, но передаёт не всё: ощущение от взаимодействия, удобство API в настоящем вызывающем коде, поведение макета с реальным объёмом данных. Иногда честный ответ — «не знаю, надо увидеть». Дальше обсуждение идёт по кругу. Попросите агента сделать версию, посмотрите и вернитесь к разговору с ответом.

Агенты снижают цену создания. Черновик, который раньше занимал день, теперь можно получить за минуты, поэтому прототипы становятся обычным шагом. Это работа [с участием человека](./Human-in-the-loop.md): прототип нужен для вашей реакции.

Обычно одного просмотра мало. Посмотрите, попросите изменить, оцените снова. Каждый цикл проясняет ещё одно решение на реальном материале точнее, чем слова.

Не весь прототип обязан быть небрежным. Части, которые вы оцениваете, можно сразу сделать с качеством рабочего продукта. Тогда выбранный компонент или API перейдёт в настоящую кодовую базу. Прототип становится полезным материалом, на который ссылается [спецификация](./Spec.md).

_Пример:_

«Полчаса спорим, делать мастер на одной странице или в три шага».

«Словами не решим. Пусть агент создаст оба варианта, пройдём их и за пять минут поймём».
