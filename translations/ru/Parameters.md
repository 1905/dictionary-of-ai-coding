Числа внутри [модели](./Model.md) — часто миллиарды, — которые настраиваются при [обучении](./Training.md). Всё, что модель «знает», заключено в них. Обучение задаёт параметры, а [инференс](./Inference.md) использует их без изменений. Другое название — _веса_.

Параметры превращают вход в выход. [Предсказание следующего токена](./Next-token%20prediction.md) — большое вычисление: [токены](./Token.md) из [контекстного окна](./Context%20window.md) проходят через операции с параметрами, и получается прогноз следующего токена. Внутри модели нет базы фактов или таблицы кода. Есть числа, устроенные так, чтобы вычисление обычно давало полезный результат. Факты, которые модель воспроизводит после обучения, например API стандартной библиотеки, — это [параметрические знания](./Parametric%20knowledge.md). Они заключены в параметрах, а не извлечены из внешнего источника.

После обучения параметры зафиксированы. Ничто в [сессии](./Session.md) их не меняет: ни ваши исправления, ни показанный код, ни разобранная ошибка. Каждая сессия работает с теми же числами. Поэтому модель [не хранит состояние](./Stateless.md), её встроенные знания ограничены [датой отсечения](./Knowledge%20cutoff.md), а сведения о проекте приходится передавать через [контекст](./Context.md). Изменить параметры можно только дополнительным обучением; по сути, после него получится другая модель.

_Пример:_

«Можно дообучить её на нашем коде?»

«Это изменит параметры — получится другая модель. Для одного проекта почти всегда дешевле передать код как контекст, чем переобучать модель».
