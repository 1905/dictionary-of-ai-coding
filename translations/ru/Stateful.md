title: "С сохранением состояния"
description: "Переносит информацию дальше. Сессия сохраняет историю ходов; память позволяет агенту переносить сведения между сессиями."

Переносит информацию дальше. [Сессия](./Session.md) сохраняет состояние между [ходами](./Turn.md): [контекст](./Context.md) накапливается, поэтому длинные сессии переходят в [зону снижения качества](./Smart%20zone.md). [Агент](./Agent.md) может сохранять состояние между **сессиями**, если [система памяти](./Memory%20system.md) записывает сведения в [окружение](./Environment.md) и загружает их в начале следующих сессий. Сама [модель](./Model.md) никогда не хранит состояние: видимую непрерывность обеспечивает [обвязка](./Harness.md), повторно передавая контекст. Противоположность — [отсутствие состояния](./Stateless.md).

Где хранится состояние:

| Уровень   | Сохранение состояния | Как устроено                                                                                                               |
| --------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Модель    | Никогда              | [Параметры](./Parameters.md) зафиксированы; виден только текущий запрос                                                    |
| Сессия    | Между ходами         | Обвязка добавляет сообщения и [результаты инструментов](./Tool%20result.md)                                                |
| Обвязка   | Между сессиями       | Файлы памяти, [AGENTS.md](./AGENTS.md.md), [материалы передачи](./Handoff%20artifact.md): записать сейчас, прочитать позже |
| Окружение | Всегда               | Файлы остаются независимо от запущенных сессий                                                                             |

Каждый уровень перечитывает данные, сохранённые ниже. Сессия кажется непрерывной, потому что обвязка повторно отправляет историю модели без состояния. Между сессиями агент «помнит», потому что обвязка загружает файлы окружения. В самой модели состояние не хранится.

Не всякое состояние полезно. Всё перенесённое влияет на дальнейшие действия, включая неверные предположения в начале разговора. [Очистка](./Clearing.md) намеренно отбрасывает состояние сессии и позволяет начать с записанных материалов.

_Пример:_

«Он помнит мои вчерашние предпочтения. Модель их выучила?»

«Нет. Обвязка записала их в файл памяти и загрузила при старте. Сама модель вчерашнего разговора не видела».
